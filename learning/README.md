# Learning route

The project asks how much an adaptive controller can recover from noisy memories in a quantum repeater chain. Understanding the answer requires both quantum-state reasoning and a careful account of successful source events and elapsed time.

The single educational anchor is Mark M. Wilde's *From Classical to Quantum Shannon Theory*, using the author notes dated 5 December 2021. The [source bridge](SOURCE_BRIDGE.md) identifies the exact version and relevant sections, translates its notation, and separates textbook foundations from the arguments supplied by this project. Reading the whole book is unnecessary.

The milestone map has two phases. Background and preliminaries assemble the local quantum objects, probabilistic resources and operational rate definition. Narrative and innovation assemble the source genealogy, adaptive counting and endpoint entanglement budget, then connect them to constructions, noise dependence and the result's boundary. Each milestone records an understanding target, earlier dependencies, its role in the story and precise source pointers.

The map is common scientific material. It records neither a reader's progress nor an assessment procedure. The worked tutorial explains a representative route through it; the complete statements and proofs remain in the [science pages](../science/README.md).
