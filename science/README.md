# Scientific reading map

The result concerns one explicit Bell-link architecture. Read its assumptions together with any rate claim. This map assigns each part of the argument one primary home.

| Question | Authoritative page | What it establishes |
| --- | --- | --- |
| Which resources and controls are allowed? | [Operational model](model.md) | Independent fresh sources and product memory noise, interval Bell swaps, endpoint interface, deterministic-horizon rate |
| Why does the upper bound cover adaptive policies and endpoint distillation? | [Adaptive converse](adaptive_converse.md) | Causal product invariant, source genealogy, pointwise profile count, entanglement budget, finite-error bound and sublinear exponent |
| How tight is the bound at finite length? | [Finite bounds](finite_bounds.md) | Exact short-lifetime regime, entanglement-weighted envelope, lattice entropy and linear-coefficient bracket |
| Which rates can be attained? | [Achievability](achievability.md) | Synchronized generation, ASAP/reset timing, fixed-deadline conversion, recurrence and hashing |
| Does another noise channel give the same law? | [Noise comparison](noise_comparison.md) | Pure phase channel, positive hashing yield, zero leading exponent for every diverging lifetime |
| What does the result mean physically? | [Interpretation](interpretation.md) | Completion time versus accumulated exposure, buffering versus generation bandwidth, model limits and unresolved coefficients |

The numerical checks in [verification](../verification/README.md) support selected algebraic identities and finite calculations. They are not substitutes for the adaptive-policy proof.
